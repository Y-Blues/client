ycappuccino client

Starts a real ycappuccino.core.framework.Framework under Pyodide and reads the DI-resolved Catalog component (example/library/catalog.py), itself wired to RemoteCrud/RemoteItemCatalog (ycappuccino.client) behind the plain ICrud/IItemCatalog interfaces. See main.py and client/README.md "Risques d'execution navigateur" before deploying this for real: this requires a pthread-enabled Pyodide build and a cross-origin-isolated page (see hosts/README.md's Host.cross_origin_isolated), neither of which could be verified in the sandbox that produced this file.
